### 4. 아직 확인하지 못한 것 (반드시 확인)
1. **노션 가져오기 결과의 필드별 정확성**: 실DB 불러오기(74행 감지)는 사용자가 확인했으나, 기간·기술 스택·성과가 원본과 일치하는지 항목별 대조 기록은 없음 (사용자가 프로필 탭에서 확인)
2. **브라우저 UI 중 AI 관련 화면**: 사용자가 UI를 확인했다고 했으나 설정 탭 AI 항목(동의, 모델 드롭다운), 공고 등록 AI 버튼, 매칭 리포트 AI 분석, 성과 다듬기, "사용 모델" 표시를 각각 확인했는지는 기록되지 않음
3. **Vercel 배포 환경**: 배포한 적 없음. 확인 항목: 보안 헤더(CSP) 때문에 화면이 깨지지 않는지, `/api/health`, 키 미등록 상태에서 BYOK 동작, **40초 시간 예산이 Vercel 요금제의 함수 최대 실행 시간 안에 들어가는지**(`vercel.json`에 실행 시간 설정 없음), 레이트 리밋은 인스턴스별 best-effort
4. **실패 모델 기억의 운영 효과**: 서버리스 인스턴스가 바뀌면 초기화되므로 배포 환경에서 얼마나 효과가 있는지는 알 수 없음

### 5. 주의사항
- 개발 서버(Vite)는 **OS 환경 변수**(예: 셸에 설정된 `GEMINI_API_KEY`)도 서버 핸들러에서 읽음. 접근 코드가 맞으면 운영자 키로 실제 Gemini 호출이 발생함
- 비밀 값은 GitHub에 올리지 않음. `VITE_` 접두사에 비밀 값 금지. `.env.local`은 `.gitignore` 대상
- 무료 Gemini 티어는 입력이 서비스 개선에 쓰일 수 있음 → UI에서 동의 체크 후에만 AI 동작
- 방문자 키·토큰은 호출 때 서버를 한 번 통과함(저장·로그 없음). 서버 운영자가 코드를 바꾸면 볼 수 있다는 구조적 한계가 있어 화면에 고지함
- 커밋 이메일은 GitHub noreply 주소로 교체 완료(2026-11-05). 새 커밋도 이 저장소 설정으로 noreply가 사용됨
- **개발 서버 운영 규칙**: 시험용으로 띄운 서버는 시험 직후 종료하고, 사용자가 보고 있는 메인 서버(포트 5173)는 사용자가 끄라고 하기 전까지 유지. 이 환경(Git Bash)에는 `pkill`이 없어 종료는 PowerShell(`Get-NetTCPConnection` → `Stop-Process`)로 함
- 실제 키로 외부 API를 호출하는 시험은 사용자의 허락을 받고 진행. 커밋·푸시는 지시가 있을 때만

# 제품 요구사항 정의서 (PRD.md)

이 문서는 **Career Intelligence**의 제품 요구사항, 타겟 사용자, 핵심 기능 명세, 사용자 여정 및 세부 정책을 정의하는 단일 진실 공급원(SSoT) 기준 문서입니다.

---

## 1. 타겟 사용자 (Target User)

### ① 주요 사용자층
- **테크 분야 구직자 및 이직 준비자**: 신입, 주니어~미드레벨 개발자(AI/데이터/백엔드/프론트엔드 등).
- **커리어 전환자**: 인접 분야나 테크 직무로 전환을 준비하며 자신의 기존 경험을 어떻게 어필할지 고민하는 구직자.

### ② 사용자 페르소나
> **페르소나: 이지은 (2년 차 데이터 분석가 / AI 엔지니어 전향 희망)**
- **상황**: 데이터 분석 업무를 하다가 AI/ML 엔지니어로 커리어 도약을 준비 중. 여러 채용 공고를 보며 지원서를 내고 있지만, 합격/불합격의 명확한 이유나 부족한 점을 객관적으로 알기 어려움.
- **불편사항 (Pain Point)**:
  - 노션, 엑셀, 폴더에 공고와 자소서가 흩어져 있어 지원 히스토리 관리가 번거로움.
  - 시중 매칭 서비스는 'Python' 단어만 보고 무조건 적합하다고 하지만 실제 면접에서는 모델 서빙 경험 부족으로 탈락함.
  - 내 경험으로 AI 엔지니어 외에 MLOps나 Data Platform 쪽도 가능한지 시야를 넓히고 싶음.
- **원하는 가치**: "내 프로젝트와 경력을 바탕으로 실제 증명할 수 있는 역량과 부족한 부분을 객관적으로 짚어주고, 지원 이력을 한곳에 안전하게 남겨두고 싶다."

## 2-1. [상세 기능 명세] 1. 커리어 프로필 & 프로젝트 자산 관리

### ① 비즈니스 규칙 및 데이터 정합성 정책
1. **단일 로컬 프로필 정책**:
   - 로컬 퍼스트 환경 특성상 기본 프로필 ID는 `'current-user'` 고정 단일 레코드로 유지되며, 프로필 수정 시 덮어쓰기 형태로 즉시 로컬 DB에 반영됩니다.
2. **기술 스택(Tech Stack) 입력 규칙**:
   - 단순 텍스트 서술이 아닌 태그 배열(`string[]`)로 강제하여 추후 JD 매칭 엔진에서 단어 토큰 단위로 정확히 분리·대조할 수 있도록 보장합니다.
   - 대소문자를 구분하지 않고 중복 입력을 자동 제거합니다 (예: `pytorch`, `PyTorch` 입력 시 하나로 통합 정규화).
3. **수행 성과(Outcomes) 불릿 분리 입력 원칙**:
   - 긴 줄글 자기소개서 형태가 아니라, **최소 1개 이상의 개별 불릿 항목(`outcomes[]`)**으로 나누어 저장합니다.
   - 각 불릿에는 '정량적 수치(예: %, ms, 건수)'나 '구체적 역할'을 담도록 입력창 하단에 안내 팁을 제공합니다.
4. **프로젝트 수행 기간(Period) 유효성**:
   - `startDate`는 필수이며, `endDate`는 진행 중(`isOngoing=true`)일 경우 비어둘 수 있습니다.
   - `startDate`가 `endDate`보다 미래 시점일 수 없습니다.
5. **프로젝트 삭제 정책**:
   - 프로젝트를 삭제하더라도, 이미 지원 이력 트래커(Application Tracker)에 '스냅샷'으로 박제된 과거 지원 건의 데이터에는 영향을 주지 않습니다 (독립 스냅샷 불변성 원칙).

## 3. 사용자 시나리오 (User Journey)

### ① 온보딩 및 프로필 자산 등록
1. 사용자가 서비스에 처음 접속하면 대시보드와 함께 프로필 작성을 유도받습니다.
2. 경력 사항과 함께 수행한 프로젝트(프로젝트명, 기간, 사용 기술 태그, 주요 역할, 정량적 성과)를 입력합니다.
3. 관심 도메인(예: 음성 AI, 헬스케어)과 희망 직무를 등록하여 내 커리어의 기본 데이터베이스를 완성합니다.

### ② 채용 공고(JD) 등록 및 파싱
1. 관심 있는 기업의 채용 공고 링크(URL)를 입력하거나, 공고 텍스트 전문을 복사하여 붙여넣습니다.
2. 파서(Parser)가 공고를 읽고 [주요 업무], [자격 요건], [우대 사항]으로 자동 분류하여 정돈된 화면을 보여줍니다.
3. 사용자가 파싱된 내용을 검토하고 필요 시 직접 수정/보완합니다.

### ③ 3단계 지능형 매칭 & Gap 분석 리포트 확인
1. 사용자의 프로필 자산(프로젝트 성과)과 채용 공고 요건을 대조합니다.
2. 결과 화면에서:
   - **직접 증명 역량**: 실제 프로젝트에서 명확한 성과를 낸 부분 확인.
   - **간접 연결 경험**: 연관 기술을 통해 어필할 수 있는 부분 확인.
   - **증거 공백 (Evidence Gap)**: 공고에서 요구하나 아직 증명되지 않은 역량을 확인하고, 이를 어떻게 자소서/포트폴리오에서 보완할지 액션 플랜을 제시받습니다.

### ④ 지원 이력 기록 및 스냅샷 보존
1. 해당 공고에 지원할 때 제출한 자기소개서 내용과 포트폴리오 링크/파일을 함께 등록합니다.
2. 지원 일자와 지원 상태(서류 접수 완료 등)를 지정합니다.
3. 이 시점의 JD, 제출 자료, 매칭 분석 결과는 **불변 스냅샷**으로 고정되어 나중에 합격/불합격 결과를 확인하고 복기할 수 있습니다.

### ⑤ Career Explorer를 통한 시야 확장
1. 탐색 탭에서 내 기술 스택을 기반으로 도전 가능한 인접 직무(Role)와 산업 분야(Domain)의 교차 매트릭스를 확인합니다.
2. 내가 가진 역량이 다른 유망 시장(예: 로보틱스, 핀테크)에서 어떻게 활용될 수 있는지 발견하고 새로운 채용 공고를 탐색합니다.

### ⑥ 사용자 맞춤형 노션(Notion) 동적 연동 시나리오
1. 사용자가 노션 API 키/DB ID를 입력하거나 노션에서 내보낸 CSV/JSON 파일을 업로드합니다.
2. 시스템이 사용자의 노션 DB 열(속성 및 타입)을 실시간으로 스캔하여 감지합니다.
3. 사용자가 직관적인 드롭다운 UI를 통해 자신의 노션 열을 [프로젝트명], [기술 스택], [기간], [수행 성과(불릿)]에 1:1로 매핑합니다.
4. 동기화 실행 시 노션에 저장되어 있던 방대한 프로젝트들이 Career Intelligence의 프로젝트 자산으로 완벽히 변환되어 저장됩니다.

## 4. 정책 및 예외 처리

### ① 데이터 저장 및 프라이버시 정책 (Local-First)
- **서버리스 로컬 퍼스트**: 민감한 자기소개서, 인적사항, 프로젝트 정보는 브라우저 내부의 IndexedDB에만 저장되며 외부 서버로 전송되지 않습니다.
- **데이터 백업 및 복원**: 사용자가 언제든 브라우저를 이동하거나 백업할 수 있도록 전체 데이터를 JSON 형식으로 내보내기/불러오기할 수 있습니다.
- **API 토큰 로컬 격리**: 노션 API 연동 키 등 민감한 인증 정보는 외부 서버로 전송되지 않고 오직 사용자의 브라우저 내에만 안전하게 보관됩니다.

### ② 외부 데이터 수집(스크래핑) 및 Fail-Safe 정책
- 채용 사이트 접근 시 `robots.txt`를 엄격히 준수하며 비정상적인 우회 시도를 하지 않습니다.
- 크롤링이 불가능한 사이트이거나 CORS 제약, 네트워크 차단이 발생할 경우 즉시 친절한 안내와 함께 **'직접 복사/붙여넣기 폼'**으로 전환되어 사용자의 작업 흐름이 끊기지 않도록 보장합니다.

### ③ 외부 DB(노션 등) 연동 정책 (동적 스키마 존중)
- **고정 스키마 강제 금지**: 사용자의 기존 노션 템플릿 변경을 강제하지 않으며, 사용자의 컬럼 구성을 최대한 존중하는 동적 매핑(Dynamic Mapping) 인터페이스를 기본 제공합니다.
- **이중 채널 지원**: 브라우저 보안(CORS) 제약에 대비하여 API 직접 연동 방식뿐만 아니라, 노션 CSV/JSON 파일 업로드를 통한 무설치 즉시 연동 방식을 함께 보장합니다.

### ③ 분석 결과의 객관성 및 신뢰성 정책
- 단순 단어 포함 여부로 역량을 과대평가하지 않습니다.
- '합격률 85%'와 같은 근거 없는 합격 예측 수치 표현을 금지하고, '직무 요건 대비 증거 충족도' 및 '보완 추천 사항'으로 객관적 피드백을 제공합니다.

### ④ 과거 지원 자료 불변성(Immutable Snapshot) 정책
- 프로필이나 프로젝트 내용을 나중에 수정하더라도, 이미 지원 완료 처리된 과거 지원 건의 JD 원문, 제출 자료, 당시 분석 결과는 그대로 보존됩니다.

## 5. 단계별 출시 범위 (Release Scope)

- **Phase 1 (5일 MVP)**:
  - 커리어 프로필 & 프로젝트 입력 관리
  - 공고 직접 입력 및 URL 기반 파싱 지원
  - 3단계 역량 분석 (직접/간접/Evidence Gap)
  - 지원 이력 트래커 (상태 파이프라인 + 불변 스냅샷)
  - Career Explorer 기본 프리셋 (주요 직무 및 도메인 교차 추천)
  - IndexedDB 저장 및 JSON 백업/복원

> 앱 화면의 안내문은 `src/features/account/policy.ts`이며 이 문서와 같은 내용입니다. 정책 버전 기록값: `2026-11-06-draft`(동의 기록 `consents.policy_version`).

## 1. 저장하는 정보
- 이메일: 로그인 ID로만 사용. 소유 확인(이메일 인증)은 도메인이 없어 아직 하지 않음.
- 암호화된 데이터: 프로필(이름·연락처는 별도 칸), 프로젝트, 과거 이력서·자소서·포트폴리오, 공고, 지원 이력, 분석 결과, 기업 자료, AI 생성 문서.
- 비밀번호는 저장하지 않음. 브라우저가 만든 "로그인용 값"의 해시만 보관.
- 동의 기록(종류·정책 버전·시각).
- 보내지 않는 것: Gemini API 키, 노션 토큰(브라우저 저장소에만 있음).

## 2. 운영자가 읽을 수 있는 것과 없는 것
- 읽을 수 없음: 모든 내용(회사명·제목·본문·날짜·이름·연락처). 내용은 브라우저에서 AES-256-GCM으로 암호화된 뒤 전송됨.
- 볼 수 있음: 이메일, 레코드 개수·크기, 수정 시각, 테이블 종류(구조 정보).
- 예외: AI 기능을 누르는 순간, 해당 문장은 평문으로 Google Gemini에 전달됨(등록한 이름·연락처와 이메일·전화·주민번호 형태는 가림, 완전하지 않음). 무료 티어에서는 입력이 서비스 개선에 쓰일 수 있음(공식 가격 안내 기준).

## 3. 복구
- 비밀번호 + 복구 키를 모두 잃으면 운영자도 복구 불가.
- 복구 키는 가입 시 1회 표시, 저장 확인 후에만 가입 완료. 복구 키 입력 5회 연속 실패 시 15분 잠금.

## 5. 삭제
- 계정 삭제 시 서버의 모든 내 데이터(키 포함) 즉시 삭제. 삭제 표시된 레코드는 30일 후 실제 삭제(서버에 암호문으로만 존재).
- 사업자 백업(복구 이력): 무료 플랜 기준 최대 약 6시간(공식 플랜 안내). 키가 삭제되어 복호화 불가.
- 이 기기의 데이터는 로그아웃 시 선택해 삭제.

2. 국외 이전 법정 고지 형식, 보유 기간

4. 이메일 인증 도입 시 문서 갱신(도메인 구입 후)
